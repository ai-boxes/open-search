# Contributing

Thanks for helping build open-search.

Before submitting a change:

1. Keep provider-specific behavior inside `open-search-providers`.
2. Keep HTTP and framework types out of `open-search-core`.
3. Add tests for behavior changes and bug fixes.
4. Run the formatting, lint, and test commands documented in `README.md`.

Please open an issue before introducing a new public API, persistent storage, or a new infrastructure dependency.
